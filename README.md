# シフト管理（申請者ページ／管理者ページ）

店舗のシフトを、スタッフからの希望集めから月のシフト作成まで通してやるための2画面。

- **申請者ページ**（スタッフ用・スマホ）… `index.html`
  カレンダーを塗るだけで希望を入力し、LINEに貼れる文章を作って送る。
- **管理者ページ**（店長用・パソコン）… `admin/index.html`
  届いた文章をまとめて貼り付けて取り込み、必要人数を見ながら割り当て、
  LINE用の文章・CSV・印刷で配る。

## 2つをつなぐもの

`shared/shift-format.js` が希望シフトの書式そのもの。申請者ページが書き、
管理者ページが読む。**ここを直すときは必ず両方の画面で確かめること。**
古い「シフト作るくん」の `am / pm / off / 13.5〜` 形式も読める。

送られる文章の形：

```
【シフト希望】2026年10月
名前：田中

× 3, 7
午前のみ 5
時間 9日 13:00-17:00
ほかの日は終日OK

メモ：20日以降は少なめで
```

## データの置き場所

どちらも**その端末のブラウザの中だけ**に保存する。サーバーは無い。
スタッフの希望は「LINEで送ってもらって、管理者が貼り付ける」でやりとりする。
管理者ページの⚙設定から、ときどきバックアップ（JSON）を取ること。

将来リアルタイムで共有したくなったら、`shared/shift-format.js` の読み書きはそのままに、
貼り付けのかわりにサーバー（Googleスプレッドシート＋Apps Scriptなど）を挟めばよい。

## 直すとき

- 直したら `sw.js` の `CACHE = "shift-v1"` の番号を1つ上げる。上げないと古い画面が端末に残る。
- アイコンは `python3 make_icons.py`。
- mainに push すると GitHub Pages に反映される（1分ほど）。
